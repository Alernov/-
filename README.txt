1. Создайте аккаунт на github.com и новый репозиторий (New repository, можно Private).
2. Нажмите "uploading an existing file" и перетащите ВСЁ содержимое этой папки (включая папки www и .github). Нажмите Commit changes.
3. Откройте вкладку Actions -> Build APK. Подождите 5-8 минут до зелёной галочки.
4. Откройте завершённую сборку, внизу в Artifacts скачайте smeta-apk (zip), распакуйте -> app-debug.apk.
5. Перекиньте на телефон, откройте, разрешите установку из неизвестных источников.
